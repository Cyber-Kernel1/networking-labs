# Networking Labs

Cisco Packet Tracer labs and network designs by **Ahmad Madi**, Cyber Security Engineering student at UCAS.

## Projects

| Project | Description | Key Topics |
|---------|-------------|------------|
| [cafe-network](cafe-network) | Secure, scalable network for a mid-sized café with dual-WAN failover | VLANs, ACLs, Dual-WAN, SSH, DHCP snooping |
| [cyberlink-networks](cyberlink-networks) | Multi-branch enterprise network with central services | OSPF, DHCP/DNS, NAT/PAT, ACLs, Port Security |

Each project folder contains a README, the Packet Tracer file (`.pkt`), the topology diagram, and full documentation.
